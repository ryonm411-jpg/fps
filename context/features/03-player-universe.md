# Feature 03 — Player Universe

## Goal
Create the initial 20–30 player universe used by the MVP.

## Player Data
Each player should have, as applicable:
- Name
- Club
- Position
- Age
- Competition
- Profile image / display asset
- Current market status
- Football statistics
- News references

## Rules
Football data informs users but does not directly set the market price.

## Acceptance Criteria
A user can browse the initial player set and open a player page with enough information to understand who the player is and why traders may care.
