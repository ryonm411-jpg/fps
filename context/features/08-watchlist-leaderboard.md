# Feature 08 — Watchlist & Leaderboard

## Watchlist
Users can add/remove players and view their watched markets from one page.

## Leaderboard
Leaderboard should compare trader performance using percentage-based performance rather than raw virtual-dollar totals.

Potential windows:
- Daily
- Weekly
- Monthly
- Season
- All-time

## Open Rules
The exact handling of virtual cash grants, resets, and leaderboard eligibility must be documented before implementation.

## Acceptance Criteria
Users can follow players and inspect performance rankings without the system favoring users simply because they received more starting or bonus capital.
